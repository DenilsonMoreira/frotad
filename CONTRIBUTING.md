# Contribuindo

## Fluxo

1. Abra ou associe a alteração a uma issue.
2. Trabalhe em branch curta: `feat/...`, `fix/...`, `chore/...`, `docs/...`.
3. Mudanças de regra de negócio devem vir acompanhadas de teste.
4. Mudanças de schema exigem migration.
5. Atualize a documentação quando houver alteração de comportamento.

## Commits

Preferência por Conventional Commits:

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `chore:`

## Pull request

Descreva:

- problema resolvido;
- abordagem;
- impacto no banco/API;
- testes executados;
- screenshots para UI;
- riscos ou decisões pendentes.
