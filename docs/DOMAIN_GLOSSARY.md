# Glossário de domínio

- **Jornada:** período operacional diário de um motorista/veículo.
- **Ciclo / viagem:** sequência operacional de uma entrega.
- **Período:** campo com início e fim; quando iniciado e não finalizado pode representar status atual.
- **Espera na obra:** período entre chegada/início de espera e início da descarga conforme workflow do cliente.
- **Volume entregue:** quantidade de concreto, normalmente em m³, associada a uma entrega/ciclo.
- **L/m³:** litros de diesel divididos pelo volume em m³ no mesmo escopo temporal definido.
- **Form template:** modelo reutilizável de formulário fornecido pelo FrotaD.
- **Form version:** snapshot imutável de um formulário publicado.
- **Submission:** preenchimento/execução de um formulário.
- **Subform:** submissão filha vinculada a outra submissão, como vários ciclos dentro de uma jornada.
- **Tenant/company:** cliente isolado dentro do SaaS.
- **Branch:** unidade operacional do cliente.
