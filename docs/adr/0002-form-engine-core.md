# ADR 0002 — Motor de formulários como núcleo

Status: Accepted

## Contexto

Clientes possuem checklists e processos diferentes. Hard-code por cliente tornaria o SaaS caro de manter.

## Decisão

Formulários configuráveis, versionados e relacionáveis serão parte estrutural do produto.

## Limites

- DSL de cálculo segura e limitada;
- tipos de campo conhecidos;
- projeções explícitas para analytics críticos;
- templates prontos para reduzir complexidade de onboarding.
